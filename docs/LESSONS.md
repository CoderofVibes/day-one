## Lessons

- **2026-10-29** — A contract unit test that built the contract twice (`setup()` twice in one `#[test]`) panicked inside near-sdk's mocked blockchain: the mock keeps storage between the two, so the second `new` collides. Rule: one contract instance per unit test; split cases into separate tests.
- **2026-10-29** — The first `test:attacks -- --record` after the redeploy failed twice for stale ids: the pay-again attack claimed against a PO that only existed on the deleted contract, and the split-purchase POs (PO-T9101/2) had been funded by the failed run and were refused as "already submitted" on the retry. Rule: a re-record after a reset uses PO ids the new contract has never seen, and the attack constants name POs that exist in the recording they ship with; cancel any throwaway PO a failed run funded before trying again (`npm run escrow` lists them).
- **2026-10-29** — near-api-js 7's `Account.getState()` returns `{ balance: { total, available, … }, storageUsage, codeHash }`, not the RPC's `amount`; the first setup run crashed on `BigInt(undefined)`. Rule: read the typings in `node_modules/near-api-js/lib/*.d.ts` before using a field, and dry-run a new script against testnet before it signs anything.
- **2026-10-29** — The credential attacks' sandbox check "escrow is 0 after the attacks" would have failed on testnet, which holds PO-1041's $612 in escrow, and the sealed round's two-hour windows only worked because the sandbox fast-forwards. Rule: a check ported from a fresh sandbox to the shared testnet contract compares before and after instead of assuming empty state, and anything timed runs on real block time there (read the windows back from the recording, not a constant).

- **2026-10-28** — NEAR AI Cloud still served the signatures of answers recorded four hours earlier, and each signed text equalled `<model>:<sha256 request>:<sha256 response>` over the bytes the adapter had hashed, so the recorded demo could be attested after the fact. Rule: run `npm run attest` right after every re-record, while the signatures are fresh; and never reformat the request or response before hashing (the adapter hashes the exact bytes it sent and received). Also: the gateway's `event_log` is a JSON string while a model entry's is already an array, `report_data` is echoed for the gateway only, and the report is 370 KB, mostly GPU evidence; keep it whole in `data/replay/` and derive the web summary from it.

- **2026-10-28** — The first plant-map screenshot showed every flow as a solid wedge: a CSS rule set `fill` on the flow group for its particle, and SVG fills an open `<path>` too. Rule: `fill: none` on every arc path, and set fills on circles only; always look at the first screenshot before tuning positions. Also: `playwright-core` lives in `tools/render`, so a one-off browser script runs from there (`npm run web:shot` already covers the common cases).

- **2026-10-28** — Git Bash rewrote the `/mnt/c/...` argument of `wsl -d Ubuntu -- bash /mnt/c/.../check.sh` into `C:/Program Files/Git/mnt/c/...` (MSYS path conversion), so WSL could not find the script. Rule: start `wsl` from PowerShell, or set `MSYS_NO_PATHCONV=1` in Git Bash.
- **2026-10-28** — In Git Bash, `kill $PID` on a background `npx tsx server.ts` killed the npm wrapper and left the node server listening; three stale APIs held three ports and the next start failed with EADDRINUSE while curl kept talking to the old code. Rule: find the listener with `netstat -ano | grep :<port>` and stop it with `taskkill //F //PID <pid>`; check the port is free before starting a server in a test. Also: a backslash in a `node -e` string through Git Bash arrives mangled (`\d` became `d`); edits with regexes go through the Edit tool.
- **2026-10-28** — In the evening unattended run, Windows had 62.8 of 63.7 GB of memory committed (another app held 10 GB; C: is 95% full, so the page file cannot grow). Every symptom traced back to it: WSL `cargo test` wrote zero-length rlibs ("memory map must have a non-zero length"), Vitest workers aborted (exit 134, 0xC0000409), and node died with "Committing semi space failed" on a 12 MB heap. Rule: when native crashes or empty build files appear, check `Get-Counter '\Memory\Committed Bytes','\Memory\Commit Limit'` before debugging code; quote the last verified run, tell Tony, and re-run later. `vitest.config.ts` keeps `maxWorkers: 2` (28 workers was never needed). In unattended runs the browser pane cannot be approved: check UI with `npm run web:shot`.
- **2026-10-28** — `wsl -d Ubuntu -- bash -lc '…"/mnt/c/Dev/NEAR Hackathon"…'` from Git Bash or PowerShell split the path at the space. Rule: put WSL commands in a `.sh` file and run `wsl -d Ubuntu -- bash <file>`.
- **2026-10-28** — GLM 5.3 Flash, given invoice text and only "Transcribe this invoice." with a strict schema, left fields empty, put its notes in a field and once returned a different vendor's invoice; naming every field in the prompt fixed all three. Rule: text prompts for structured reads name each field and what it holds; and a check that guards money never depends on the model reading right (the instruction screen and PO match run on the raw text and the ledger).
- **2026-10-28** — Three guessed test numbers for the extraction were wrong (BR-B-1046 has 7 materials, not 8; MGO is line 3; 1,377.9 lb is 625,004,927 mg), and ASC-261009-01 stays "released" after Plant B empties it because Plant A still books 12.550 kg. Rule: take expected values from the bake-off files and the ledger, never from memory of the story; a lot's state follows its total balance across plants.
- **2026-10-28** — Anthropic structured outputs refused the extraction schema twice: more than 16 union-typed (nullable) fields, then "compiled grammar is too large" for a nested 11-field-per-row array. NEAR AI's strict json_schema took both. Rule: for Anthropic, use "" instead of null and keep each call's schema small; test a new schema against every provider on the route before relying on it.
- **2026-10-28** — Playwright's usual setup downloads a few hundred MB of Chromium; `playwright-core` with `channel: "msedge"` drives the Edge every Windows PC already has, for 14 MB, and renders byte-identical JPEGs.
