- **2026-10-29** — A `useFrame(cb, 1)` added for a label pass that had to run after the labels silently stopped the 3D twin rendering: in React Three Fiber any positive priority means "I render myself", and the screenshot script's draw-call count went to 0 while frames still counted. - **2026-10-29** — The 3D twin's DOM labels (`drei/Html`) are sized in pixels while their anchors are in the world, so a camera that framed world boxes clipped plant names at the stage edge, and labels stacked by world units overprinted at far shots; and the label div only exists after drei's own React root renders, so a `useEffect` that measured it on mount read nothing.
