## Lessons

- **2026-10-28** — Git Bash rewrote the `/mnt/c/...` argument of `wsl -d Ubuntu -- bash /mnt/c/.../check.sh` into `C:/Program Files/Git/mnt/c/...` (MSYS path conversion), so WSL could not find the script. Rule: start `wsl` from PowerShell, or set `MSYS_NO_PATHCONV=1` in Git Bash.
- **2026-10-28** — In Git Bash, `kill $PID` on a background `npx tsx server.ts` killed the npm wrapper and left the node server listening; three stale APIs held three ports and the next start failed with EADDRINUSE while curl kept talking to the old code. Rule: find the listener with `netstat -ano | grep :<port>` and stop it with `taskkill //F //PID <pid>`; check the port is free before starting a server in a test. Also: a backslash in a `node -e` string through Git Bash arrives mangled (`\d` became `d`); edits with regexes go through the Edit tool.
- **2026-10-28** — In the evening unattended run, Windows had 62.8 of 63.7 GB of memory committed (another app held 10 GB; C: is 95% full, so the page file cannot grow). Every symptom traced back to it: WSL `cargo test` wrote zero-length rlibs ("memory map must have a non-zero length"), Vitest workers aborted (exit 134, 0xC0000409), and node died with "Committing semi space failed" on a 12 MB heap. Rule: when native crashes or empty build files appear, check `Get-Counter '\Memory\Committed Bytes','\Memory\Commit Limit'` before debugging code; quote the last verified run, tell Tony, and re-run later. `vitest.config.ts` keeps `maxWorkers: 2` (28 workers was never needed). In unattended runs the browser pane cannot be approved: check UI with `npm run web:shot`.
- **2026-10-28** — `wsl -d Ubuntu -- bash -lc '…"/mnt/c/Dev/NEAR Hackathon"…'` from Git Bash or PowerShell split the path at the space. Rule: put WSL commands in a `.sh` file and run `wsl -d Ubuntu -- bash <file>`.
- **2026-10-28** — GLM 5.3 Flash, given invoice text and only "Transcribe this invoice." with a strict schema, left fields empty, put its notes in a field and once returned a different vendor's invoice; naming every field in the prompt fixed all three. Rule: text prompts for structured reads name each field and what it holds; and a check that guards money never depends on the model reading right (the instruction screen and PO match run on the raw text and the ledger).
- **2026-10-28** — Three guessed test numbers for the extraction were wrong (BR-B-1046 has 7 materials, not 8; MGO is line 3; 1,377.9 lb is 625,004,927 mg), and ASC-261009-01 stays "released" after Plant B empties it because Plant A still books 12.550 kg. Rule: take expected values from the bake-off files and the ledger, never from memory of the story; a lot's state follows its total balance across plants.
